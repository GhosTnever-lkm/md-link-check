# Участие в разработке

Спасибо за интерес к md-link-check! Проект без зависимостей, на Python 3.10+.

## Как запустить тесты

```bash
python -m unittest discover -s tests -t .
```

## Перед отправкой изменений

1. Добавьте тест на новое поведение или на исправленную ошибку.
2. Обновите `CHANGELOG.md` в разделе `[Unreleased]`.
3. Проверьте, что тесты проходят локально и CI зелёный.

## Правила

- Не добавляйте зависимости без веской причины: инструмент должен работать из коробки.
- Не добавляйте в тесты реальные секреты, ключи и токены.
- Один коммит — одна логическая правка.

Сообщения об уязвимостях — см. [SECURITY.md](SECURITY.md).
